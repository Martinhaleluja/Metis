# Metis .NET rebuild source

The plan this rebuild followed was supplied as an external document,
`LULU_DOTNET_REBUILD_PLAN.md`, written before the project was renamed to Metis.
It is no longer present on this machine, so this file records what it asked for
rather than linking to it.

This repository implements its functionality-first order: native foundation, companion, hold-to-talk input, active-window capture, Gemini `generateContent`, readable diagnostics, optional speech, then guidance and bounded automation.
