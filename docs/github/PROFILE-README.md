### Metis

I build **[Metis](https://github.com/Martinhaleluja/Metis)** — a Windows
assistant that teaches you to use your computer instead of using it for you.

Ask it what is on your screen, or how to do something, and it explains while
drawing on the thing you are looking at. Then you do it. It cannot click, type
or move your pointer, and there is no setting that lets it — because a tool that
does the task for you cannot also be the thing that teaches you to do it.

It is written in C# and .NET 8, runs on your own machine with your own AI
provider key, and blacks out anything an application marks as private before it
looks.
